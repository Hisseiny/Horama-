# D5 : le faux SaaS de démonstration est une brique P0

Date : 16 novembre 2026. Décidé par Nathan (CAO).

**Décision.** Le faux SaaS (tableau de bord, liste des factures, détail d'une facture, versions 12 et 13, régressions activables par paramètre) est construit dans tous les cas, par Nathan, dans `faux-saas/`. Il n'est plus un plan B.

**Pourquoi.** Le pilote ne mettra pas de bugs volontaires dans son environnement de test en trois jours ; le banc a besoin d'une dizaine de régressions activables ; le « comment tester » de vendredi doit marcher sans accès au pilote.

**Conséquence pour la démo.** Sur le vrai SaaS du pilote : les tests écrits depuis sa vraie documentation, joués pour de vrai. Sur le faux SaaS : les régressions placées exprès, le banc, la dérive documentaire. Le faux SaaS est présenté au jury comme une application de démonstration.
