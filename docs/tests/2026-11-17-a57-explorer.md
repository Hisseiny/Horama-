# A57 — moteur visuel à un agent

Implémentation hors ligne uniquement, statut « codé non testé ». Aucun site réel,
aucune session H ou requête Holo réelle, aucune modification du vault du dépôt.

Les tests `agent/exploration-explorer.test.ts` injectent la découverte HTTP, la
session H, les contrôles CDP, Holo et les PNG ; ils utilisent une base en mémoire
et un vault temporaire. Ils vérifient la synthèse atomique, C4, les références et
notes, les passages successifs, zones ignorées et décisions, les relevés refusés,
les pages non visitées, les captures hors cadre et les échecs réseau/session.
Le raccord WebSocket réel et l'affichage de la scène ne sont pas vérifiés.

Vérifications exécutées : `pnpm install && pnpm -r --if-present run check`.
Le premier lancement a trouvé une erreur du faux HTTP des nouveaux tests :
`Response` déclarait du texte brut pour les pages HTML ; le découvreur les
écartait correctement. Le faux indique désormais le bon type de contenu.
Après correction : `pnpm --filter @horama/agent check`, 139 tests réussis,
zéro échec (avant ajout des cas complémentaires de session et d'identifiants).

Dernière vérification complète, après les cas complémentaires et le raccord
d'annulation des contrôles :

```text
Scope: all 7 workspace projects
Already up to date
Done in 4ms using pnpm v12.18.0
agent check: # tests 143
agent check: # pass 143
agent check: # fail 0
agent check: Done
```

Les checks de `contrats`, `faux-saas`, `memoire`, `interface` et `jugement`
se terminent aussi par `Done`. Un PNG minimal initialement mal encodé dans le
nouveau cas de tailles différentes a été remplacé par un PNG généré avec les
outils standard de Node ; le cas vérifie bien « tailles différentes ».

La provenance sitemap est indicative : le moteur observe un XML utilisable
pendant la découverte, sans pouvoir distinguer chaque lien de chaque entrée du
sitemap. Les durées et coûts réels restent à mesurer. Relecture humaine des
constats et passage réel sur Eugenia restent à faire.
