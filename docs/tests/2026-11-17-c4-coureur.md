- Les C4 sont transmis à `writeReport` au lieu de la liste vide. Le C6 reste inchangé : son état d’exécution ne devient pas un verdict métier.

Une session terminale échouée, un relevé manquant, une règle non évaluée ou une erreur du vérificateur/références/mémoire produit `INCONCLUSIVE` avec une raison. Sans règle calculée complète, aucun `PASS` global n’est émis. Si une règle est non évaluée, le test reste non concluant même si une autre règle a un verdict. Sinon un défaut calculé prime sur un doute visuel, puis le doute prime sur la conformité. Un test multirègle agrège les valeurs/calculs ; le champ singulier C4 `regle` n’est renseigné que pour un test monorègle, sans extension du contrat.
