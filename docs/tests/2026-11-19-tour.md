- `accueil/envoye.js` : chaque exploration envoyée est gardée dans le navigateur (`horama-explorations`, 30 au plus), pour la tour.
- Liens vers la tour : sous le champ de la page d'accueil (« Tous les passages et leurs constats : la tour de contrôle »), et sous le titre du rapport servi sur le web (`extension/rapport.js`, seulement en `http(s)`, recopié dans `accueil/rapport/`). Le `.zip` de l'extension est refait.
- Aucune donnée d'exemple : le nom « Jane Doe » du contexte du prototype est retiré du code construit ; ni « Facturo » ni les écrans d'exemple ne sont dans le JavaScript servi.
- Le constat de langue des passages publiés avant le 19/11 est dit en phrase (« Un bloc est resté en français sur une page déclarée en allemand. »).
