## Ce que fait l'option

`--sans-presentation` joue le même parcours, par le même coureur (`creerCoureur`), sans les présentations de la mascotte ni les pauses de lecture : chaque constat est tracé et compté sans phrase, aucune bulle, `--choix` répond dès que la question est posée, pas d'attente de 350 ou 900 ms pour regarder. Restent : la pause entre deux gestes du script (`--rythme`), le clic retenu, le dessin des traits (les questions de la fin en ont besoin), l'écran de fin.

Machine Linux de Devin (Chrome for Testing 156, écran `:0`), Facturo en ligne (`https://facturo-demo.vercel.app`), mode scripté, base en mémoire. Aucune session H.

1. Références v12 prises sur cette machine dans une copie du vault (les références du repo viennent d'un Mac : sur Linux, le rendu des polices donne 66 doutes) :
   `node parcours.mjs --version 12 --ecrire-references --sans-agent --sans-fin --rythme 1 --vault essais/vault-ref --sortie essais/ref --profil essais/profil --fermer-chrome`
2. Pour chaque passage, une copie neuve de `essais/vault-ref`, puis, depuis `automatisation/scene/` :
   `node parcours.mjs --sans-agent --sans-base --rythme 2 --choix bug,voulu,bug,voulu,bug,voulu,bug,voulu --vault essais/vault-<n> --sortie essais/passage-<n> --profil essais/profil --fermer-chrome [--sans-presentation]`
   `--rythme 2` fixe la pause entre deux gestes (sans elle, entre 2 et 4 s au hasard) pour que les deux modes soient comparables.
3. Durée totale : horloge murale du processus, du lancement de `node` à sa sortie (Chrome lancé puis fermé compris). Durée du coureur : `duree_s` de `passage.json` (`rapport.passage`).

## Identique entre les deux modes

Comparé par un script (`pngjs`, un pixel diffère si un de ses quatre canaux RGBA diffère, sans tolérance), pour chaque paire :

- relevés : 4 sur 4, `1280 × 900`, **0 pixel différent** sur chacun (`tableau-de-bord--defaut`, `liste-des-factures--defaut`, `detail-facture--defaut`, `liste-des-factures--filtre-echeance`), textes identiques ; aussi 0 pixel entre les deux passages sans l'option ;
- `constats` de `passage.json` identiques en entier (6) ; compteur `{ bons: 2, problemes: 2, doutes: 1, sans_conclusion: 0 }` ; bilan « J'ai fini. 2 problèmes et 1 doute. On les regarde ensemble. » ;
- décisions : les trois mêmes fichiers dans le vault, identiques hors `passage_id` et `le` (`2026-11-17-liste-des-factures-ca-du-mois` bug, `…-filtre-echeance-depassee` voulu, `…-exporter` bug) ;
