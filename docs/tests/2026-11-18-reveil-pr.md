Couloir Nathan. `automatisation/reveil/pr.mjs` : le Mac interroge GitHub pour les PR ouvertes du site cible. Il attend le déploiement Vercel Preview réussi du dernier commit de chaque PR, lit les fichiers modifiés, choisit les tests par le champ `code:` des notes (`choisirTests` d'`impact.mjs`), puis lance la scène sur l'adresse de prévisualisation. ## Tests unitaires

`node --test automatisation/reveil/*.test.mjs automatisation/impact/*.test.mjs` : 17 réussis sur 17, dont les 4 de `pr.test.mjs`.
- **Lecture de GitHub** (réponses factices) : PR ouvertes ; déploiement d'environnement « Preview – … » ; adresse prise dans `environment_url` du statut `success` ; fichiers de la PR.
- **Une PR n'est jouée qu'une fois**, sur son dernier commit, et seulement quand sa prévisualisation est prête.
- **Les fichiers de la PR choisissent les tests** par le champ `code:` des notes : un fichier de l'accueil retient le test de l'accueil et écarte celui des programmes.
- **Ce que reçoit la scène** : `impact.json` écrit, puis `parcours.mjs` avec `--impact`, `--base-url <prévisualisation>`, `--logiciel`, `--vault`, `--pr <adresse>`, `--sortie` et les options transmises (`--vitrine`). Une PR qui ne touche aucun écran ne lance pas la scène.
