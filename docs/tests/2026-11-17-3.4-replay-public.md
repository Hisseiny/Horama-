## Comportement

`agent/src/session.ts` appelle `POST /sessions/{id}/share` après le suivi et l’arrêt du pont. Le champ `share_url` est résolu contre l’origine API régionale pour les chemins relatifs. Toute URL absolue HTTPS est acceptée, même sur un autre hôte : l’hôte réel du replay n’est pas vérifié et ne doit pas être supposé identique à celui de l’API. Les liens HTTP et les schémas non HTTPS sont refusés.

Un lien absent ou invalide, une erreur HTTP ou réseau produisent un avertissement explicite, sans lien inventé ni modification de l’état d’exécution pour ce seul manque de métadonnée optionnelle. `ResultatSession.replay_url` est propagé par le coureur aux trois tests de la session partagée, puis au Markdown. C6 dispose déjà de `tests[].replay_url` : aucun contrat modifié.

Source documentaire : <https://hub.hcompany.ai/agents-api/sessions/share.md> ; méthode `share_session` du SDK Python `hai-agents` 1.5.1 inspectée lors de la préparation A7.
