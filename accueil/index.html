Il visite comme un visiteur.

Il fait défiler, clique, lit les textes, regarde les images. Son curseur bouge sous vos yeux, page après page.

Le code vérifie ce qu'il croit voir.

Un lien a l'air mort ? Horama interroge le serveur. Un texte a l'air coupé ? Il mesure la boîte. Seul ce qui est mesuré devient un défaut.

Il revient avec deux piles.

Les défauts prouvés, entourés d'un trait rouge, avec leur mesure. Et les doutes, soulignés de points : ceux-là, c'est vous qui les tranchez.
